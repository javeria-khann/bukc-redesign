# BUKC Redesign

An unofficial Bahria University Karachi Campus website redesign / educational clone built as a frontend portfolio project.

## Disclaimer

Unofficial redesign project for portfolio purposes only. Not affiliated with Bahria University.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui-style local components
- Lucide React icons

## Scope

This project is intentionally frontend-only. It has no backend, database, authentication, admin panel, payment flow, or official university integration.

## Sections

- Home
- About
- Admissions
- Academics / Programs
- News & Events
- Campus Life
- Research & Innovation
- Contact
- Downloads / Quick Links

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Portfolio Safety

All written content is original placeholder content inspired by a university website experience. The project does not use official Bahria University logos, images, branding assets, or official contact channels.
